# Параллельное программирование — умножение матриц

Серия лабораторных работ по перемножению двух квадратных матриц в четырёх реализациях.

- [Лабораторная 1](reports/lab_01/README.md) — последовательная версия.
- [Лабораторная 2](reports/lab_02/README.md) — OpenMP.
- [Лабораторная 3](reports/lab_03/README.md) — MPI (запуск на суперкомпьютере «Сергей Королёв»).
- [Лабораторная 4](reports/lab_04/README.md) — CUDA.
- [Лабораторная 5](reports/lab_05/README.md) — фрактал Мандельброта на `std::thread` (Stanford CS149 asst1, Program 1): `make lab_05`.

## Архитектура

Вся общая логика — в одном файле [src/matrix.hpp](src/matrix.hpp). В `src/lab_XX/` лежит только способ распараллеливания: последовательный цикл, OpenMP, MPI или CUDA. Все версии на одних данных дают один и тот же результат — меняется только время.

Матрицы хранятся в текстовом виде (первая строка — размер n, дальше n строк по n чисел), элементы — цифры 0–9, поэтому файл можно открыть и увидеть, что именно перемножается.
